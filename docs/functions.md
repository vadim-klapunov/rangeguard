# Справочник функций RangeGuard

RangeGuard состоит из анализатора диапазонов и модуля, который связывает его с Visual Studio Code. Ниже описаны именованные функции обоих модулей и обработчики, передаваемые другим функциям.

## Модуль `src/analyzer.js`

### `analyze(text)`

Разбирает содержимое файла `.ranges` и проверяет диапазоны. При ошибках входных данных прекращает проверку покрытия и пересечений. Если входные данные можно анализировать, ищет выходы за общую область, пропуски и пересечения.

Параметры:

- `text` (`string`) — полный текст проверяемого файла `.ranges`.

Возвращает объект:

- `domain` — общая область с полями `min`, `max` и `line` либо `null`, если область не удалось распознать.
- `rules` — массив распознанных правил. Каждое правило содержит `name`, включённые целочисленные границы `min` и `max` и номер строки `line`.
- `issues` — массив сообщений. Каждое сообщение содержит номер строки `line` и текст `message`.
- `valid` — признак того, что проверка покрытия и пересечений выполнена. Значение `true` не исключает наличие пропусков, пересечений и выходов за общую область.

Номера строк в результате отсчитываются с нуля.

### `report(line, message, blocking = true)`

Внутренняя функция `analyze`. Добавляет сообщение в массив `issues`. Для блокирующей ошибки отмечает, что проверку покрытия и пересечений продолжать нельзя.

Параметры:

- `line` (`number`) — номер строки, к которой относится сообщение; отсчёт начинается с нуля.
- `message` (`string`) — текст сообщения о проблеме.
- `blocking` (`boolean`, по умолчанию `true`) — признак того, что ошибка препятствует проверке покрытия и пересечений.

Возвращаемого значения нет.

### `validNumber(value)`

Проверяет, является ли значение безопасным целым числом JavaScript в пределах от −1 000 000 000 до 1 000 000 000 включительно.

Параметры:

- `value` (`number`) — число, которое нужно проверить.

Возвращает `true`, если число удовлетворяет ограничениям, иначе `false`.

### `segment(min, max)`

Формирует текстовое представление участка для диагностического сообщения.

Параметры:

- `min` (`number`) — левая включённая граница участка.
- `max` (`number`) — правая включённая граница участка.

Возвращает строку. Если границы совпадают, возвращает одно число, например `5000`; иначе возвращает диапазон, например `[1000, 1005]`.

### `findMatchingRules(result, value)`

Находит все правила, диапазоны которых содержат указанное число.

Параметры:

- `result` (`object`) — результат вызова `analyze`, из которого берутся общая область и распознанные правила.
- `value` (`number`) — целое число, для которого нужно найти подходящие правила.

Возвращает массив подходящих правил в порядке их записи в файле. Массив пуст, если подходящих правил нет, анализ заблокирован ошибками, число недопустимо или находится вне общей области.

### Внутренние обработчики

**Сравнение диапазонов при сортировке**

- `first` (`object`) — первый сравниваемый диапазон.
- `second` (`object`) — второй сравниваемый диапазон.

Возвращает результат сравнения левых границ, а при их равенстве — правых границ. Отрицательное число помещает первый диапазон перед вторым, положительное — после него, ноль означает равенство границ.

**Отбор правил в `findMatchingRules`**

- `rule` (`object`) — очередное правило из результата анализа.

Возвращает `true`, если искомое число лежит между включёнными границами правила, иначе `false`.

## Модуль `src/extension.js`

### `activate(context)`

Запускается Visual Studio Code при активации RangeGuard. Регистрирует команды и обработчики событий, создаёт коллекцию диагностических сообщений и проверяет уже открытые документы.

Параметры:

- `context` (`vscode.ExtensionContext`) — контекст расширения, в котором регистрируются ресурсы для освобождения при деактивации.

Возвращаемого значения нет.

### `checkDocument(document)`

Внутренняя функция `activate`. Передаёт текст документа в анализатор и обновляет сообщения RangeGuard для этого документа.

Параметры:

- `document` (`vscode.TextDocument`) — открытый или сохранённый документ Visual Studio Code, который нужно проверить.

Возвращает результат `analyze` для документа с идентификатором языка `ranges` или `null` для другого языка.

### `escapeMarkdown(text)`

Внутренняя функция обработчика экспорта. При формировании отчёта экранирует разметку в названиях правил, путях и диагностических сообщениях. Переносы строк заменяет пробелами.

Параметры:

- `text` (`string`) — исходный текст, который нужно вставить в Markdown как обычный текст.

Возвращает строку с экранированными специальными символами.

### Обработчики команд

| Команда | Действие | Параметры и результат |
| --- | --- | --- |
| `rangeguard.check` | Проверяет активный файл и, если есть проблемы, открывает панель Problems. | Параметров нет. Возвращаемого значения нет. |
| `rangeguard.checkValue` | Запрашивает целое число и показывает, каким правилам оно соответствует. Предупреждает о пропуске, пересечении или выходе за общую область. | Параметров нет. Асинхронный обработчик не возвращает полезного значения. |
| `rangeguard.exportReport` | Проверяет текущий текст, в том числе несохранённые изменения, и открывает новый Markdown-документ с результатами. | Параметров нет. Асинхронный обработчик не возвращает полезного значения. |

### Другие внутренние обработчики

**Преобразование сообщения анализатора в диагностику редактора**

- `issue` (`object`) — сообщение анализатора с полями `line` и `message`.

Возвращает объект `vscode.Diagnostic` для соответствующей строки документа.

**Проверка ввода в команде поиска значения**

- `text` (`string`) — строка, введённая пользователем в поле ввода.

Возвращает текст ошибки, если ввод не является допустимым целым числом, или `null`, если ввод корректен.

**Получение названия совпавшего правила**

- `rule` (`object`) — одно из правил, которым соответствует введённое число.

Возвращает название правила. Названия объединяются для показа сообщения о пересечении.

**Обработка закрытия документа**

- `document` (`vscode.TextDocument`) — закрытый документ, для которого нужно удалить диагностические сообщения.

Удаляет сообщения для этого документа. Возвращаемого значения нет.

При открытии и сохранении документа используется функция `checkDocument(document)`, описанная выше.

## Пример вызова анализатора

Из корня проекта запустите Node.js и выполните:

```js
const { analyze, findMatchingRules } = require('./src/analyzer');

const text = 'domain: 0..10\nМалый: [0, 5)\nБольшой: [5, 10]';
const result = analyze(text);

console.log(result.issues); // []
console.log(findMatchingRules(result, 5).map(rule => rule.name)); // ['Большой']
```
