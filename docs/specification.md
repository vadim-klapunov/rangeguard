# Техническое задание: RangeGuard

## 1. Назначение

RangeGuard — расширение для Visual Studio Code, предназначенное
для проверки правил, заданных числовыми диапазонами.

Области применения: тарифы, скидки, игровые уровни, пороги
мониторинга и группировка данных.

## 2. Формат входных данных

Расширение обрабатывает текстовые файлы с расширением .ranges.

Первая содержательная строка задаёт общую область проверки:

domain: 0..100

Обе границы области включены.

Каждая следующая содержательная строка задаёт правило:

Название: [0, 50)

Квадратная скобка включает границу, круглая — исключает.
Допускаются сочетания [a, b], [a, b), (a, b] и (a, b).
Пустые строки и строки, начинающиеся с #, игнорируются.

Названия правил должны быть непустыми и уникальными.
Двоеточие отделяет название от диапазона.

## 3. Ограничения

Обрабатываются только целые числа от -1000000000 до 1000000000.
Отрицательные значения разрешены.
Дробные числа и бесконечные границы не поддерживаются.

В файле должна быть ровно одна область domain
и хотя бы одно правило.

Правила рассматриваются независимо: порядок строк
не задаёт приоритет.

Каждое целое число общей области должно принадлежать
ровно одному правилу.

## 4. Возможности

1. Проверка формата файла и корректности числовых границ.
2. Обнаружение повторяющихся названий правил.
3. Обнаружение обратных и пустых диапазонов.
4. Обнаружение выхода диапазонов за общую область.
5. Поиск участков общей области, не покрытых правилами.
6. Поиск пересечений правил внутри общей области.
7. Отображение сообщений в панели «Проблемы» VS Code
   с привязкой к строкам документа.
8. Проверка при открытии и сохранении файла, а также
   по команде «RangeGuard: Проверить диапазоны».
9. Команда «RangeGuard: Проверить значение»: ввод целого
   числа и вывод всех правил, которым оно соответствует.
10. Команда «RangeGuard: Экспортировать отчёт»:
    создание нового Markdown-документа с результатами
    проверки для последующего сохранения пользователем.

При ошибках формата, обратных или пустых диапазонах
проверка покрытия и пересечений не выполняется до исправления.
Пользователь получает сообщения о причинах.

При выходе корректного диапазона за общую область
выдаётся отдельное сообщение. Проверка покрытия
и пересечений проводится в пределах общей области.

## 5. Интерпретация границ

Поскольку значения целые, диапазон [0, 5) содержит
числа 0, 1, 2, 3, 4.

Диапазон (0, 5] содержит числа 1, 2, 3, 4, 5.

Диапазон [5, 5] содержит одно число 5.
Диапазон (5, 6) не содержит целых чисел и считается пустым.

## 6. Архитектура

package.json — описание расширения, регистрация языка и команд.

src/extension.js — взаимодействие с VS Code:
обработка событий, команды, диагностика и открытие отчёта.

src/analyzer.js — разбор текста, проверка диапазонов
и поиск подходящих правил для введённого числа.

Анализатор работает независимо от интерфейса VS Code.
Для хранения правил и сообщений используются массивы объектов.
Проверка покрытия выполняется по границам диапазонов,
без перебора всех чисел общей области.

## 7. Проверка работоспособности

Необходимо проверить:

- корректное покрытие области без пересечений;
- пропуск одного числа и нескольких чисел;
- пересечение двух правил и вложенные диапазоны;
- включённые и исключённые границы;
- отрицательные числа;
- обратный и пустой диапазоны;
- выход за общую область;
- неправильный формат и повтор названия;
- отсутствие domain или правил;
- поиск правил для введённого значения;
- обновление сообщений после исправления файла;
- создание Markdown-отчёта.

## 8. Результат работы

Рабочее расширение VS Code, исходный код в публичном
репозитории GitHub, примеры файлов, документация
и отчёт по лабораторной работе.
